## 🧭 About Me

I'm an **AI Engineer, Full-Stack Engineer, and Cloud Architect** focused on building production-ready AI systems, multi-agent workflows, SaaS platforms, and scalable cloud infrastructure.

I work across the entire stack — from **AI agent architecture and LLM orchestration** to backend APIs, databases, payments, cloud infrastructure, and production deployment.

My recent work has focused heavily on **multi-agent systems using LangGraph, LangChain, LangSmith, FastAPI, and OpenAI-based agent architectures**.

### What I Build

- 🤖 **Multi-Agent AI Systems** — specialized agents, orchestration, state management, tool calling, and agent workflows
- 🧠 **LLM Applications** — RAG, structured outputs, memory, reasoning workflows, and AI-powered automation
- 🔗 **LangGraph & LangChain Systems** — stateful agent graphs, persistence, tools, and multi-step workflows
- 📊 **LangSmith Observability** — tracing, debugging, and monitoring AI agent workflows
- ⚡ **FastAPI Backends** — production-ready Python APIs and AI services
- 🌐 **Full-Stack Applications** — React, Next.js, Node.js, Express, MongoDB, PostgreSQL
- ☁️ **Cloud Architecture** — AWS, Azure, Docker, CI/CD, scalable infrastructure
- 💳 **Payment Integrations** — payment workflows, transaction handling, and subscription systems
- 🗺️ **Google & Geospatial APIs** — location-aware search, Google APIs, and basic geospatial data handling
- 🔄 **AI Automation** — autonomous workflows connecting AI with external APIs and business systems
